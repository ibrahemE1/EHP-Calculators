# EHP - الحاسبات الهندسية

القائمة الرئيسية: `index.html` (اللوجو + زر التثبيت على الهاتف)

- filter.html : نظام البحث عن الفلاتر
- viscosity.html : حاسبة لزوجة الزيت
- pipe.html : حساب التدفق للمواسير
- cylinder.html : الحاسبة الهيدروليكية للسلندر

## الرفع على GitHub Pages
1. أنشئ Repository وارفع محتويات المجلد (مع assets و .nojekyll).
2. Settings ← Pages ← Deploy from a branch ← main / root ← Save.
3. الرابط: https://USERNAME.github.io/REPO/

عند تعديل أي ملف غيّر رقم النسخة في sw.js (ehp-v1 ← ehp-v2) ليتحدث التطبيق على الهواتف.
